# AGC — контейнер для Агата

*In English: [AGC.md](AGC.md).*

Файл `.agc` — это одна программа и всё, что нужно для её запуска: образ диска,
машина, настройки и клавиатура.

Иметь образ диска и знать, как его запускать, — не одно и то же. Какая машина —
Агат-7 или Агат-9, и сколько в ней памяти? Какая модель прерывания, если от
неверной музыка в игре уезжает на октаву? И какая клавиша на клавиатуре, что
лежит перед вами, посылает тот байт, которого ждёт программа? Ничего этого в
`.dsk` нет, и чаще всего это не записано нигде. Контейнер хранит всё это рядом с
образом, в одном файле, который человек может прочитать и поправить.

Это JSON. Перетащите такой файл на
[эмулятор](https://amaltsev.github.io/agat-web/) — и он запустится.

---

## Пример

```json
{
  "agc": 1,
  "title": "RISE OUT",
  "author": "Andrew Maltsev",
  "date": "1989",
  "url": "https://github.com/amaltsev/agat-web",
  "notes": "Со звуковыми данными в исходном виде, 1989 год.",

  "machine": { "model": 7, "ram": 64 },
  "quirks":  { "irq": "raster", "rate": 0 },

  "keys": {
    "KeyW": { "code": "^", "note": "Выстрел вправо" }
  },

  "media": [
    {
      "name": "rise-out.dsk",
      "data": [
        "AQIDBAUGBwgJCgsMDQ4PEBESExQVFhcYGRobHB0eHyAhIiMkJSYnKCkqKywtLi8wMTIzNDU2",
        "…"
      ],
      "patches": [ { "at": 45312, "hex": "A9 60 85 84" } ]
    }
  ]
}
```

Обязателен только `agc`, а на практике ещё и `media`: у всего остального есть
разумные значения по умолчанию, и контейнер, в котором нет ничего, кроме образа,
тоже правильный.

## Поля

### Что это за программа

| поле | |
|---|---|
| `agc` | версия формата — `1`. Именно по этому ключу файл и опознаётся. |
| `title` | название программы |
| `author` | автор |
| `date` | **текст**, а не число: `"1989"`, `"около 1985"`, `"1990-92"` |
| `url` | откуда взято или где описано |
| `notes` | проза: происхождение, благодарности, что делает патч. Код это поле не читает. |

`date` — текст, потому что о программе такого возраста известен чаще период или
предположение, чем год; контейнер, который не умеет сказать «около 1985»,
заставил бы написать `1985` и соврать.

Часто именно эти поля — последнее место, где всё это вообще записано. Заполняйте
их.

### `machine`

| поле | |
|---|---|
| `model` | `7` или `9` |
| `ram` | **килобайты**: `32`, `64` или `128`. Только для Агат-7 — в Агат-9 всегда 128К. |

Объём памяти здесь не для красоты: он маскирует поле страницы в регистре
видеорежима, то есть программа его видит, и диск, рассчитанный на 64К, на 128К
может не пойти.

Машина, названная здесь, считается **выбранной** — `7a` или `9a` в имени файла
её уже не переопределит.

### `quirks`

| поле | |
|---|---|
| `irq` | `"raster"`, `"held"` или `"pulse"` — как внутрикадровое прерывание доходит до процессора |
| `rate` | частота этого прерывания в герцах; `0` — как машина сама решит |

`raster` — это железо, каким его измерили, и частоту оно задаёт само, поэтому
`rate` при нём не используется. Две другие модели — прочтения того же железа из
agat-emulator, оставленные для сравнения; см.
[HARDWARE.md](HARDWARE.md#the-delivery-model).

Это важно для всего, что строит звук по счёту прерываний, — а это почти вся
музыка на Агате: и высота, и темп берутся прямо отсюда, и между `held` и
`raster` разница в октаву.

### `keys` — переназначение клавиатуры

Клавиатура Агата — не ваша клавиатура. Программа, которая читает `^`, ждёт
`$5E`: в ЛАТ это <kbd>Shift</kbd>+<kbd>6</kbd>, а в РУС — <kbd>X</kbd>. Найти
можно, но не тогда, когда в вас стреляют.

```json
"keys": {
  "KeyW": { "code": "^", "note": "Выстрел вправо" },
  "KeyA": "←"
}
```

Слева — браузерный
[`KeyboardEvent.code`](https://developer.mozilla.org/docs/Web/API/UI_Events/Keyboard_event_code_values):
`KeyW`, `Digit1`, `ArrowUp`, `Space`. Он обозначает **физическую клавишу**, а не
символ, поэтому переназначение одинаково работает при любой раскладке хоста.

Справа — либо код, который надо послать, либо `{ "code": …, "note": … }`. Код
пишется одним из трёх способов:

| вид | пример |
|---|---|
| сам символ | `"^"`, `"@"`, `"Ю"` |
| шестнадцатерично | `"$5E"`, `"0x5E"` |
| по имени | `"Up"`, `"Down"`, `"Left"`, `"Right"`, `"Enter"`, `"Esc"`, `"Space"`, `"Tab"`, `"Bksp"`, `"F1"`, `"F2"`, `"F3"` |

Символами покрывается `$20`–`$7F` — это ASCII плюс кириллица Агата в порядке
КОИ-7 Н2, так что `"Ю"` и `"Ч"` пишутся как есть. Единственная ловушка — `$24`:
Агат рисует в этом месте `¤`, а не `$`, поэтому пишите `"¤"` или `"$24"`.

Переназначенная клавиша **забирается целиком**: она посылает свой код в обеих
раскладках и с РЕГ и УПР и без них. Клавиша управления, меняющая смысл оттого,
что игрок держит модификатор, была бы хуже, чем отсутствие переназначения. То,
что клавиша посылала раньше, пока контейнер загружен, недоступно — поэтому
занимайте клавиши, которые программе больше не нужны.

`note` говорит, что клавиша **делает**. Это и есть та половина, ради которой всё
затевалось: экранная клавиатура показывает эту подпись, и при наведении на `^`
читается **`W (Выстрел вправо)`** вместо того, чтобы человек это выяснял сам. Из
этих же подписей потом вырастет режим «только те клавиши, которыми играют».

### `media`

Список, загружается по порядку. Диски попадают в тот дисковод, который их
прочтёт; `.fil` кладётся прямо в память.

| поле | |
|---|---|
| `name` | исходное имя файла. **Формат определяется по размеру, а не по нему** — образы Агата в природе сплошь и рядом названы неправильно. |
| `data` | base64 строками |
| `patches` | изменения, применяемые после раскодирования, по порядку |

`data` — обычный base64, без сжатия: контейнер остаётся текстовым файлом, внутрь
которого можно заглянуть любыми привычными средствами. Строки по 76 символов —
это 57 байт и целое число групп base64, поэтому каждая строка самостоятельна.
При чтении принимается и одна длинная строка, и строки любой другой длины.

Контейнер несёт всё, что понимает эмулятор: `.aim`, `.dsk` и `.nib` на 140К и
840К, а также программы `.fil`. Контейнер внутри контейнера не допускается.

### `patches`

```json
"patches": [ { "at": 45312, "hex": "A9 60 85 84" } ]
```

`at` — смещение в байтах от начала раскодированных данных, `hex` — что туда
записать. Пробелы и запятые разрешены, так что байты можно сгруппировать так,
как они читаются.

Данные остаются **образом ровно в том виде, в каком он был найден**, а изменения
живут здесь. В этом весь смысл разделения: контейнер несёт нетронутую копию
того, откуда он взялся, изменение видно всякому, кто откроет файл, а сохранение
загруженного контейнера пишет обратно то, что в нём лежало, а не пропатченный
результат.

**То, что программа записала на диск, сохраняется точно так же.** Снятый с
блокировки дисковод 140К пишет в лежащий в памяти поток нибблов; при сохранении
каждая записанная дорожка читается обратно в те 16 секторов, из которых была
собрана, а разница попадает сюда. Игра, хранящая рекорд, обходится патчем в
несколько сотен байт, а не второй копией диска, и читается так же, как любой
другой патч.

Дорожка, которая не читается обратно секторами — диск, отформатированный иначе,
или запись, оборванная на середине, — не имеет секторного образа, разницей от
которого мог бы стать патч. Тогда сохраняется весь поток нибблов: данные `.nib`
и никаких патчей. Файл получается больше и скучнее, но ничего не теряет и
загружается без каких-либо дополнительных сведений — носители опознаются по
размеру.

## Как сделать контейнер

### Из эмулятора

**Save AGC** записывает контейнер по состоянию машины: что вставлено в
дисководы, модель и объём памяти, обе настройки прерывания, действующее
переназначение клавиш и всё, что программа записала на снятый с блокировки
диск. Ничего не спрашивает.

Контейнер, загруженный из файла, сохраняет своё название и имя файла. Сделанный
из голого образа берёт имя образа и туда, и туда: `game.dsk` сохранится как
`game.agc` с названием `game.dsk`. Переименуйте и откройте в текстовом
редакторе, чтобы дописать автора, дату и клавиши.

### Из командной строки

```sh
node tools/mkagc.js game.dsk \
  --title="…" --author="…" --date=1989 --url=https://… \
  --model=7 --ram=64 --irq=raster \
  --key="KeyW:^:Выстрел вправо" > game.agc
```

`--key` — это `КЛАВИША:КОД:ПОДПИСЬ`, разбирается по первым двум двоеточиям, и
может повторяться. `--patch=СМЕЩЕНИЕ:HEX` задаёт патч напрямую, а
`--diff=<изменённый образ>` вычисляет патчи сам, сравнив изменённую копию с
исходной, — обычно патч именно так и получается.

## Как загрузить

Перетащите файл на страницу, откройте через **Open…** или назовите его в адресе:

    index.html#agc=examples/rise-out.agc

Вариант с адресом файл загружает по сети, поэтому нужна страница, отданная
сервером: на `file://` `fetch` запрещён и остаётся **Open…**. Контейнер
применяется первым, а остальные ключи адреса — после него, так что
`#agc=…&model=9` пробует программу на другой машине, ничего не правя в файле.

Все консольные инструменты принимают контейнер везде, где принимают образ, и
запускают его на той машине, которую он называет:

```sh
node tools/check.js sniff game.agc    # что за файл и что в нём написано
node tools/check.js boot  game.agc    # загрузить и доложить, докуда дошло
node tools/shot.js        game.agc    # загрузить и записать экран в PNG
```

## Если вы пишете свою реализацию

- Версия — это `agc`. Файл с неизвестной версией лучше отвергнуть, чем угадывать.
- Опознавайте контейнер по ключу `agc`, а не по расширению.
- Незнакомые поля надо сохранять, а не выбрасывать. Контейнеры часто правят
  руками, и читатель, молча теряющий непонятое, рано или поздно съест чьи-то
  записи.
- `ram` — в килобайтах, `date` — строка. И то и другое легко переврать во второй
  реализации.

Эталонная реализация — [`src/agc.js`](src/agc.js): около 200 строк, без
зависимостей, чтение и запись в одном файле.
