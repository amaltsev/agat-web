Click the screen and type. Return, Esc, arrows and Ctrl+letter are passed through; sound starts on the first keypress, as browsers require. Keys go through the Agat's own scancode table, so ЛАТ/РУС switches to a JCUKEN layout and Cyrillic comes from where a key sits rather than from what your host keyboard types. Boot is the equivalent of PR#N — it restarts from the disk. Reset cold-starts into the machine's own monitor, which is where you land with no disk in.

Keyboard Draws the mapping rather than leaving you to guess it — the Agat's own board, or the PC keys the table maps — with the cap your keypress reaches lit and $C000 shown underneath. Switching ЛАТ/РУС moves the lit cap and greys out what the other layout can no longer type: РУС cannot reach ' , / ; and ЛАТ cannot reach Ю, Ч or Ъ. Caps can be clicked, so a key your host will not send is still reachable, and hovering one names every host key that reaches it.
Takes .aim tagged track images, .dsk sector images and .nib nibble images — 140K and 840K of each — plus .fil program files. Format is detected by size, not by extension, because Agat images in the wild are routinely misnamed.
.agc An Agat Container: one of those images plus the machine it wants, the interrupt settings it was tuned for, and a keyboard remap — so a game whose controls are four keys away under a Shift can put them where your fingers are. Save AGC writes one from the machine as it stands. The format is written up in AGC.md, and по-русски.
Drives 840K in slot 5 on both machines; 140K in slot 6 on the Agat-9 and slot 3 on the Agat-7. A dropped image goes to whichever drive can read it. Each drive's lamp is dim while its motor is running and bright while bytes are reaching the CPU — a boot of ten seconds is normal, and looks like one — and T beside it is the track its head is on.
⚙ The interrupt model, its rate and the volume. The first two are the ones to reach for when sound comes out at the wrong pitch: they set how the sub-frame interrupt reaches the CPU, and software that sequences sound on the interrupt count hears the choice as pitch and tempo. An .agc carries both, so a program tuned by ear stays tuned.
Machine The Agat-9 is 128K in 8K banks. The Agat-7 is 32/64/128K in 16K banks and the size is visible to software, so set it to match your disk. A filename containing 7a or 9a picks the machine for you until you choose one yourself.
Bookmarks The machine, its RAM size, both interrupt settings and which keyboard is up ride in the address, so a configuration that runs a program properly can be kept or passed on. #agc= names a container, which carries the program itself.
