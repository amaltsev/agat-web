Click the screen and type. Return, Esc, arrows and Ctrl+letter are passed through; sound starts on the first keypress, as browsers require. Keys go through the Agat's own scancode table, so ЛАТ/РУС switches to a JCUKEN layout and Cyrillic comes from where a key sits rather than from what your host keyboard types. Boot is the equivalent of PR#N — it restarts from the disk. Reset cold-starts into the machine's own monitor, which is where you land with no disk in.

Keyboard Draws the mapping rather than leaving you to guess it — the Agat's own board, or the PC keys the table maps — with the cap your keypress reaches lit and $C000 shown underneath. Switching ЛАТ/РУС moves the lit cap and greys out what the other layout can no longer type: РУС cannot reach ' , / ; and ЛАТ cannot reach Ю, Ч or Ъ. Caps can be clicked, so a key your host will not send is still reachable, and hovering one names every host key that reaches it.
Takes .aim tagged track images, .dsk sector images and .nib nibble images — 140K and 840K of each — plus .fil program files. Format is detected by size, not by extension, because Agat images in the wild are routinely misnamed.
AGC An Agat Container: one of those images plus the machine it wants, the interrupt settings it was tuned for, a keyboard remap — so a game whose controls are four keys away under a Shift can put them where your fingers are — and the controls themselves, grouped, which is the card under the screen. Save AGC writes one from the machine as it stands. The format is written up in AGC.md, and по-русски.
Drives 840K in slot 5 on both machines; 140K in slot 6 on the Agat-9 and slot 3 on the Agat-7. A dropped image goes to whichever drive can read it. Each drive's lamp is dim while its motor is running and bright while bytes are reaching the CPU — a boot of ten seconds is normal, and looks like one — and T beside it is the track its head is on.
RO / RW Every disk arrives read-only, and the drive tells the program so. Click RO to let it write — which is what an Agat-9 system disk wants when it says «СИСТЕМА ИСПОРЧЕНА», and what DOS needs before it will SAVE or INIT. Writes go to memory and nowhere else: the image on your disk is never touched, and closing the tab loses them. Save AGC keeps them, as patches on the disk they came from. Only the 140K drive writes.
⚙ The three memory sizes, the interrupt model, its rate and the volume. The interrupt settings are the ones to reach for when sound comes out at the wrong pitch: they set how the sub-frame interrupt reaches the CPU, and software that sequences sound on the interrupt count hears the choice as pitch and tempo. An .agc carries all of it, so a program tuned by ear stays tuned.
Machine The Agat-9 is 128K in 8K banks, and nothing about it is adjustable. The standard Agat-7 is three separate devices — 64K of base RAM in 16K banks, a 32K ЭмПЗУ card in slot 2 behind $D000-$FFFF, and a 32K ОЗУ expansion in slot 4 that can take $8000-$BFFF over from base RAM — which is the 128K machine most software was written for. The expansion powers up deselected, so $8000-$BFFF is base RAM until a program claims it. Only the base RAM is scanned by the video controller, and its size masks the mode register's page field, so set that one to match your disk. A filename containing 7a or 9a picks the machine for you until you choose one yourself.
Bookmarks The machine, all three memory sizes, both interrupt settings and which keyboard is up ride in the address, so a configuration that runs a program properly can be kept or passed on. #agc= names a container, which carries the program itself.
