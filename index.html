Drop an Agat image into the window and it starts running, or click one of the bundled examples below.

Pause Holds the machine still. Nothing is saved and nothing is lost — the clock stops, and goes on from where it was. Boot, Reset and dropping a file all mean run this, so any of them starts a paused machine again. Save AGC pauses for as long as its panel is up.
Keyboard The Agat's own board, or the PC keys the table maps. The cap your keypress reaches is lit, with $C000 shown underneath. Caps can be clicked, and hovering one names every host key that reaches it. Most host keys pass through. Keys go through the Agat's scancode table, so ЛАТ/РУС switches to a JCUKEN layout.
Mouse Off by default. The mouse goes red in the status line while nothing is reading the card, and green while the machine has the pointer. Click the screen to hand the pointer over and Esc to take it back. The host left button is A, right is B. On a touchscreen the screen is a trackpad instead: strokes steer, a tap is A, a second finger is B. The trackpad option gives the desktop pointer the same behavior. The two buttons are also drawn over the screen's lower corners.
Takes .aim tagged track images, .dsk sector images and .nib nibble images — 140K and 840K of each — plus .fil program files. Format is detected by size, not by extension. Opening replaces what was open, drives and all; files opened together stay together, so a 140K and an 840K dropped at once fill both drives and are saved as one container. Open into drive… on a drive's ⋯ is the one that adds instead.
AGC An Agat Container: one of those images plus the machine it wants, a keyboard remap, the controls themselves, grouped, which is the card under the screen, and what the program is — title, author, date, where it came from, a description, and one line to whoever is about to play, which is the card below that. Save AGC writes one from the machine as it stands, and asks whether the machine itself should go in with it — the RAM, the CPU, the drive heads, so that the container reopens where it was left rather than booting. The format is written up in AGC.md.
Drives By default 840K is in slot 5 on both machines; 140K is in slot 6 on the Agat-9 and slot 3 on the Agat-7, one drive on each. A dropped image goes to whichever drive can read it. Each drive's lamp is dim while its motor is running and bright while bytes are reaching the CPU; T beside it is the track its head is on. A container can ask for a second drive on either controller, and then the lamps say D1 and D2.
RO / RW Disks are read-only by default. Click RO to allow writing. Writes go to memory, and closing the tab loses them. Save AGC keeps them, as patches on the disk they came from. The lock is the disk's and follows it from drive to drive.
⋯ The drive: which disk is in it, Rename, Eject, Blank — a disk of nothing, to INIT from DOS — and Open into drive…, which changes that one disk and leaves the session running. The list holds every disk the session has, a container's spares included, so an editor booted from one disk can save to another. View/Edit DOS files under it is that disk's catalog, and what each file can be taken off or put onto it with: View opens a file — as text, as a BASIC listing, as hex at the address it loads, or as the 6502 instructions there — and edits it if it is a T one. It edits the disk in the drive, so the machine reads what is written and Save AGC keeps it — a running DOS re-reads the catalog for every command, so the next CATALOG shows the change. The machine is held while the panel is up. The same panel is a page of its own at edit-dos.html, for a disk that is not in a drive, and what a container says — its title, the machine it wants, the keys it is played with, the media it carries — is edit-agc.html.
⚙ Which Agat this is, its memory sizes, the mouse, the monitor, the volume and mute, with Boot and Reset.
Machine The Agat-9 is 128K in 8K banks on the motherboard, plus a 128K ОЗУ expansion in slot 2. The standard Agat-7 is three separate devices — 64K of base RAM in 16K banks, a 32K ЭмПЗУ card in slot 2, and a 32K ОЗУ expansion in slot 4.
Bookmarks The machine, its memory sizes, the monitor and which keyboard is up ride in the address, so a configuration that runs a program properly can be kept or passed on. #agc= names a container, which carries the program itself — a path beside the page, or an https:// URL to one hosted anywhere that lets this page fetch it, so a container needs no copy here to be linked and run.
